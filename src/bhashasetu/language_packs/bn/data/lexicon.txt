# BhashaSetu seed lexicon - Bengali surface forms, roughly frequency-ordered.
#
# THIS IS A SEED, NOT A DICTIONARY. It exists so Phase 1 runs offline with no
# licence-encumbered data. It is far too small to support confident NON_WORD
# detection on real prose, which is exactly why `BengaliLexicon.coverage_factor`
# damps NON_WORD confidence in proportion to size - with this list loaded, most
# non-word flags land in `CheckResult.suppressed` rather than in front of a user.
#
# Run `make fetch-dicts` to install bn_BD + bn_IN Hunspell dictionaries; the
# lexicon switches to them automatically and confidence rises on its own.
#
# Ordering is load-bearing: earlier lines outrank later ones when suggestions tie
# on edit distance.
