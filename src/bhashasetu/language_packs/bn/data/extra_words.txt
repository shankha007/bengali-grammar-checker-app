# Supplement to the Hunspell dictionary: correct Bengali that bn_BD rejects.
#
# Every shipping spell-checker carries one of these. The entries here were found
# by running the bundled seed lexicon and the clean gold slice through bn_BD and
# reviewing what it rejected - not by patching whatever the eval happened to
# flag. Two systematic gaps showed up:
#
#   1. চলিত future-tense forms (করব, থাকবে, দেখব, পারব)
#   2. সাধু finite forms (দিয়াছে, যাহার, আমাদিগের)
#
# A word added here will never be flagged as NON_WORD, so the bar is "a careful
# editor would not change this", not "I have seen it written somewhere".
#
# Do NOT add a word merely because it appears in the gold set. If the eval
# disagrees with the dictionary, decide which one is wrong first.
